# Reactive Family (G1)

**These elements are "reactive" because small changes produce dramatically different outputs.**

This is the action family—from giving instructions to autonomous operation. A single word change in a prompt can completely transform the output. An agent given slightly different goals will take entirely different actions.

The Reactive family represents the spectrum of human-AI interaction, from direct instruction to full autonomy.

---

## Family Characteristics

- **High sensitivity to input:** Small changes create large output differences
- **Action-oriented:** These elements make things happen
- **Escalating autonomy:** From human-directed to AI-directed behavior

## Learning Path

**Foundation:** Master [Prompts](/docs/periodic-table/reactive/prompts)—the fundamental interface between human intent and AI capability.

**Practitioner:** Learn [Function Calling](/docs/periodic-table/reactive/function-calling) and [Agents](/docs/periodic-table/reactive/agents)—bridging AI reasoning to real-world systems.

**Expert:** Explore [Multi-agent](/docs/periodic-table/reactive/multi-agent)—orchestrating multiple autonomous systems.

---

## Key Insight

The Reactive family teaches you that **AI systems are not deterministic machines**. They're probabilistic systems where the interface (prompts) and the autonomy level (agents) dramatically affect outcomes. Mastering this family means understanding how to craft effective instructions and when to let the AI take control.
